# Rclone Browser Next Mobile 0.4.0

## 更新內容

- **記憶卡與 USB 隨身碟：** 位置選單新增儲存空間清單並顯示可用容量，支援直接瀏覽、傳檔及用外部 App 開啟。
- **資料夾書籤：** 將常用路徑加入書籤，可從位置選單快速切換。
- **紫、藍、綠三色主題：** 支援淺色、深色或跟隨系統，App 桌面圖示也可隨配色切換。
- **瀏覽設定：** 新增緊湊清單、本機圖片與影片縮圖、顯示隱藏檔、啟動預設位置及返回鍵離開方式。
- **傳輸設定：** 可調整同時傳輸數、速度上限、慢速網路等待時間，以及行動數據傳輸前提醒。
- **設定檔與權限管理：** 支援匯入與匯出 rclone 設定檔，並可在設定頁查看權限狀態與清除暫存。

## 安裝與使用

下載 `RcloneNext-0.4.0-arm64.apk` 安裝於 Android 8 以上的 ARM64 裝置（內建官方 rclone 1.75.2 引擎，可直接覆蓋舊版）。

設定位於右上角「⋮」選單。切換桌面圖示顏色時，部分手機可能會移除桌面捷徑，重新從 App 清單拉出即可。匯出的設定檔含可還原的密碼，請妥善保管。
