# Rclone Browser Next Mobile 0.4.0

**0.4.0 是目前最穩定的版本，建議更新到這一版。**

## 這次更新

- **記憶卡與 USB 隨身碟：** 位置面板新增儲存空間清單，顯示剩餘空間，可瀏覽、複製檔案，並用其他 App 開啟。
- **資料夾書籤：** 把常用資料夾加入書籤，之後從位置面板直接開啟。
- **紫、藍、綠三種配色：** 可搭配淺色、深色或跟隨系統；App 圖示也能跟著配色切換。
- **瀏覽設定：** 可選緊湊清單、圖片與影片縮圖、顯示隱藏檔、啟動時的位置，以及返回鍵的離開方式。
- **傳輸設定：** 可調整同時傳輸的檔案數、速度上限與網路等待時間，也能在使用行動數據傳送遠端檔案前先詢問。
- **連線設定檔：** 可匯入、匯出 rclone 設定，並在設定頁管理檔案存取與通知權限、清除暫存資料。

## 安裝與使用

下載 `RcloneNext-0.4.0-arm64.apk`，在 Android 8 以上的 ARM64 裝置安裝。沿用先前版本的簽章，可以直接覆蓋更新。內含官方 rclone 1.75.2 引擎。

設定入口在右上角「⋮」選單。切換主畫面圖示顏色時，部分手機可能移除原有捷徑，可從 App 清單重新拖回主畫面。匯出的連線設定包含可還原的密碼，請妥善保管。
