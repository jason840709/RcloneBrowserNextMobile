# 使用手冊

## 選擇位置與瀏覽模式

點窗格左上角的位置圖示，可切換本機、記憶卡、USB 隨身碟，或新增遠端連線、匯入 rclone 設定檔。右上角「⋮」選單可切換「單頁」、「分頁」或「雙窗格」模式（雙窗格可拖曳中間分隔列調整比例）。

搜尋功能僅篩選目前資料夾內的檔案與資料夾名稱，不會搜尋子資料夾內部。長按項目可進入多選模式。

## 複製與移動

選取檔案後，單頁與分頁模式可按底部「複製」或「移動」，切到目的資料夾再按「貼上」；雙窗格可直接點「複製到…」或「移動到…」傳往另一側。

遇到同名檔案會直接略過、不覆蓋（同名資料夾則會合併內容）；移動時若略過同名檔案，來源檔案會保留。

同一儲存空間內移動整個資料夾，且目的資料夾尚不存在時，rclone 可直接移動整個資料夾。跨儲存空間或合併既有資料夾時，仍由 rclone 逐檔處理。

## 重新命名

選取單一檔案或資料夾後，選「重新命名」。本機與記憶卡使用系統改名操作，內容不需重新傳送。遠端改名會先檢查連線是否支援；不支援時會顯示原因。已有相同名稱時會保留原檔，請改用其他名稱。

## 同步資料夾

未選取檔案時，點雙窗格中間的「同步設定」。最後點選的窗格預設為來源，另一側為目的地（可按「對調」反轉方向）。同步只會修改目的地，分為兩種模式：

- **只補上缺少的檔案**：只複製目的地沒有的檔案，不覆蓋也不刪除既有檔案。
- **讓目的地和來源一模一樣**：補齊缺少的、覆蓋不同的檔案，並刪除目的地多出的檔案與空資料夾。

點「先比對」會先預覽變更清單，不改動檔案，也可隨時停止。比對沒有總時間上限，請讓 App 留在畫面上；切換到其他 App 可能暫停或中斷。點「直接開始」會省略比對，其中「讓目的地和來源一模一樣」仍會再確認。比對後若檔案有變動，實際結果可能與清單不同。

若錯誤可能使清單不完整，App 不會依該清單刪除目的地多出的檔案；若錯誤只影響個別檔案寫入，或檔案、資料夾的修改時間，且兩邊清單完整，仍會依比對結果刪除多餘檔案。

空資料夾會另外逐一確認：只有來源不存在、目的地確實為空才刪除。部分來源無法讀取時，其對應的目的地內容會保留，其他可確認的多餘空資料夾仍會清理，工作也仍會顯示錯誤。來源已有的空資料夾會保留，但目的地在它底下多出的空子資料夾會清除。

## 連線設定

內建 **SMB**（NAS／Windows 共用資料夾）、**SFTP**（SSH 伺服器）與 **WebDAV**（如 Nextcloud）連線表單。填寫主機或網址、帳號與密碼即可儲存；點連線右側的「⋮」可移除連線（不影響遠端檔案）。

Google 雲端硬碟、OneDrive 等服務請先在電腦上用 rclone 設定好，再匯入未加密的 `rclone.conf`（支援密碼經 rclone obscure 遮蔽的設定檔，不支援整份加密的設定檔）。遮蔽的密碼仍可還原，設定檔應當作登入資料保管。匯入會取代手機上現有的所有連線，若有需要請先匯出備份。已有設定時會先確認；成功匯入後會清除舊的遠端清單與尚未貼上的項目。

## 傳輸紀錄與取消

點右下角進度膠囊或從「⋮ → 傳輸紀錄」可查看進行中、排隊中與已結束的工作（已結束最多保留 50 筆）。進行中與排隊中的工作皆可單獨取消；取消後已傳完的檔案會保留。

點選任一紀錄可開啟「傳輸詳細」，查看各項統計數字與逐檔清單（每類最多列出前 500 筆，出錯資料夾最多列出 300 個）。

App 若被系統在背景強制終止，不會自動續傳。重新傳輸前請先確認目的地有沒有留下不完整檔案，以免同名略過規則保留它們。

## 記憶卡、書籤與設定

- **書籤**：在資料夾右上角「⋮」可加入或移除書籤，之後從左上角位置選單快速開啟。
- **外觀與瀏覽**（「⋮ → 設定」）：可切換紫／藍／綠配色、深淺色、桌面圖示配色、緊湊清單、本機縮圖、顯示隱藏檔、啟動位置與返回鍵行為。
- **傳輸設定**：可調整同時傳輸數（1／2／4／8）、同時比對數（自動／4／8／16／32）、速度上限、慢速網路延長等待，以及行動數據傳輸提醒。
- **備份設定檔**：匯出的 `rclone.conf` 內含可還原的密碼，請妥善保管。
- **清除暫存**：不會刪除連線設定或傳輸紀錄。

## 常用工作

在「同步設定」或「傳輸詳細」點「存成常用工作」，之後可從右上角「⋮ → 常用工作」快速執行（複製會直接開始、移動會先確認、同步會開啟同步設定面板）。

常用工作可以改名與刪除，目前沒有定時執行。

## 同步比對方式

在「設定 → 傳輸 → 比對方式」或同步設定面板中可切換「讓目的地和來源一模一樣」如何判斷同名檔案有變更：

| 比對方式 | 判斷規則 |
| --- | --- |
| 大小與修改時間（預設） | 大小或時間不同即視為變更。若只有時間不同，且兩邊能提供相同種類的雜湊值，內容相同時只更新時間、不重傳；否則可能重傳整個檔案 |
| 只比對大小 | 僅比對檔案大小、忽略修改時間。適合無法保留修改時間的目的地，但不會更新大小相同而內容不同的檔案 |
| 大小與內容 | 忽略修改時間，大小相同時再比對檔案雜湊值。計算雜湊可能需要讀完整個檔案；若兩邊無共同雜湊演算法，則改為只比對大小 |

比對方式只影響「讓目的地和來源一模一樣」。複製、移動與「只補上缺少的檔案」仍會略過同名檔案。同時比對數選「自動」時，為同時傳輸數的兩倍，最少 8 個。

同步完成後會抽查目的地檔案的修改時間；若目的地未保留修改時間，詳細頁會提醒並提供切換為「只比對大小」的捷徑。

## 記憶卡不支援的名稱

目的地為 FAT／exFAT 記憶卡或隨身碟時，結尾是句點或空格的名稱會直接略過、不自動改名；格式無法辨識的記憶卡也採用這項規則。「先比對」會套用相同規則。詳細頁的「略過」會列出最上層符合的項目，更深層的名稱也會略過，但不逐一列出。

在「讓目的地和來源一模一樣」模式下，若記憶卡上已有被系統截掉結尾的舊檔，因為名稱與來源不同，可能被當成多餘檔案刪除；原名存不了的檔案不會重新補回。其他不被目的地接受的名稱會列為出錯，App 不會自行換名；連線端的名稱解讀沿用 rclone 規則。

## 匯出傳輸分析報告

在「傳輸紀錄」或「傳輸詳細」頁面點「匯出分析報告」，會將報告存至 `Download/RcloneNext報告` 資料夾（單份上限 100 MB），並可直接按「分享」傳送。

報告依既有紀錄產生，不會重新掃描檔案。正常檔案僅列統計，錯誤與只在目的地的項目各可保留最多 5,000 筆路徑，並包含同步資料夾核對數量與保留原因。超出限制或舊紀錄未保存的項目，會標明省略筆數。「比對時只在目的地」是比對結果，是否已刪除要看最後的刪除結果。

報告會嘗試遮蔽錯誤原文中的帳號密碼與網址參數，仍包含檔案路徑、連線名稱與裝置資訊，分享前請先檢查全文。目的地拒絕建立來源同名資料夾時，工作仍屬未完成，App 不會自行改名。

## 清理 0.7.1 重複檔案

若曾使用 0.7.1 版，可至「設定 → 傳輸 → 清理 0.7.1 重複檔案」，檢查過去傳輸紀錄中的本機或記憶卡目的地。工具會列出名稱含「`‛`」、且同一層仍有原檔的重複項目；確認後才刪除重複的那份。找不到原檔的項目只列出，不刪除。
