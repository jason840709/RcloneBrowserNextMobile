# 使用手冊

## 選擇位置與瀏覽方式

點窗格左上角的手機或雲朵圖示，可以開啟手機資料夾、新增遠端連線，或匯入 rclone 設定。瀏覽模式可從窗格右上角「⋮」選單切換為單頁、分頁或上下雙窗格。雙窗格的分隔列可以拖曳調整高度。

搜尋只比對目前資料夾內項目的名稱，不會搜尋子資料夾內部。長按一個項目進入選取模式，再點其他項目即可多選。

## 複製與移動

選取後按底部「複製」或「移動」，切換至目的資料夾，再按「貼上」。雙窗格會直接提供傳送到另一側的按鈕。

已有同名檔案會略過，即使內容不同也不覆蓋。同名資料夾會合併未重名的內容。移動遇到略過項目時，來源仍保留。目前沒有逐檔覆蓋選項。

## 同步資料夾

取消檔案選取後，按雙窗格中間的「同步設定」。最後點過的窗格預設為來源，另一個窗格為目的地。「對調」會交換傳輸方向，不會交換畫面位置。請依面板的「來源」與「目的地」標籤再次核對，再選擇只補上缺少檔案，或讓目的地和來源一樣。

按「先比對」只比對、不修改檔案。檢查清單後，再按執行按鈕。也可選「直接開始」。「讓目的地和來源一模一樣」直接開始前會再確認，全部傳完且沒有出錯才刪除目的地多出的檔案。比對時會顯示進度，可以停止，沒有總時間上限。請讓 App 留在畫面上。執行前後若資料變動，實際結果也可能與比對結果不同。

## 連線設定

新增連線表單支援 NAS 常用的檔案分享方式 SMB、加密檔案傳輸方式 SFTP，以及透過網址讀寫檔案的 WebDAV。填寫主機或網址、帳號與密碼後儲存。連線右側的「⋮」可移除連線，遠端檔案仍會保留。

其他服務可匯入既有、整份未加密的 rclone 設定。密碼遮蔽與整份設定加密不同。密碼被 rclone 遮蔽的設定可以匯入，但整份加密的設定目前無法匯入。遮蔽的密碼可還原，設定檔應當作登入資料保管。

匯入會取代全部現有連線。已有設定時會先確認。取消確認會保留原設定；確認匯入成功後，會清除舊的遠端清單與尚未貼上的項目。

## 查看與取消傳輸

傳輸時點右下角進度，或從右上角「⋮」選單開啟「傳輸紀錄」。頁面分為進行中、排隊中與已結束，每筆都列出操作方式、來源與目的地。已結束的紀錄最多保留 50 筆，可以清除全部或刪除單筆。

點一筆紀錄可開啟詳細頁，查看結果數字、逐檔紀錄、比對方式與傳輸設定。每一類逐檔紀錄最多保存前 500 項，數字仍計入全部檔案。進行中與排隊中的工作可以單獨取消。升級前沒有記下數字的舊紀錄仍可查看方向、再做一次或存成常用工作。

取消會保留已完成的檔案。程序被系統終止後不會自動續傳。重傳前應先檢查目的地是否留下不完整檔案，避免同名略過規則保留它們。


## 記憶卡、書籤與設定

位置面板會列出本機、記憶卡和 USB 儲存空間及剩餘容量。可在目前資料夾的右上角「⋮」選單加入或移除書籤。

右上角「⋮ → 設定」可調整紫藍綠配色、深淺色、圖示配色、清單密度、縮圖與隱藏檔，也可設定啟動位置和返回鍵行為。改變主畫面圖示時，部分手機可能移除捷徑，需要從 App 清單重新拖回。

傳輸設定可選同時傳輸 1、2、4 或 8 個檔案、速度上限，以及延長慢速網路等待時間。開啟行動數據確認後，使用行動網路傳送 NAS 或雲端檔案前會先詢問。

設定頁也能匯出連線設定檔。拿到設定檔的人可以還原其中的密碼，請勿公開分享。清除暫存不會刪除連線設定或傳輸紀錄。

## 常用工作

在傳輸詳細頁或同步設定按「存成常用工作」，之後從右上角「⋮ → 常用工作」按「執行」。複製會直接開始，移動會先確認，同步會打開原本方式的同步設定。常用工作可以改名與刪除，目前沒有定時執行。

## 同步的比對方式

「設定 → 傳輸」可以調整「比對方式」與「同時比對的檔案數」。同步設定選「讓目的地和來源一模一樣」時，也能直接變更比對方式。

| 比對方式 | 兩邊有同名檔案時怎麼處理 |
| --- | --- |
| 大小與修改時間（預設） | 大小或時間不同就視為變更。只有時間不同、兩邊有共同的檔案指紋（雜湊值）時，內容相同可只更新時間；沒有共同指紋時可能整個重傳 |
| 只比對大小 | 相同大小就略過，不檢查內容，因此可能略過大小相同但內容不同的檔案 |
| 大小與內容 | 不比修改時間，使用兩邊共有的檔案指紋判斷內容；兩邊沒有共同指紋時會改成只比大小 |

比對方式只影響「讓目的地和來源一模一樣」。複製、移動和「只補上缺少的檔案」仍然略過同名檔案，不覆蓋。

同時比對數可選自動、4、8、16 或 32。自動沿用原有規則，至少 8 個，或同時傳輸數的兩倍。

同步傳完後會抽查一個檔案的修改時間。如果目的地沒有保留時間，App 會提醒下次可能重傳。可依用途改成只比對大小，或在雙方支援共同指紋時選大小與內容。只比對大小無法找出同大小的內容變更。
