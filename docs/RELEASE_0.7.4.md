# Rclone Browser Next Mobile 0.7.4

- **清理多餘空資料夾**：同步時若僅個別檔案寫入失敗，仍會核對來源並清理目的地多出的空資料夾（來源原有的空資料夾或無法確認來源者會保留），且不再重跑整個同步工作。
- **記憶卡名稱過濾**：傳送到 FAT／exFAT 記憶卡或隨身碟時，結尾為句點或空格的名稱會直接略過、不改名。完整同步仍會刪除目的地多出的項目，略過的檔案不會重新補回。
- **錯誤與資料夾明細**：詳細頁與報告新增「刪除的資料夾」、「略過的名稱」及各資料夾錯誤統計，方便排查失敗位置。
- **匯出傳輸報告**：詳細頁可匯出並分享傳輸報告（含設定、結果與錯誤明細）。報告內含路徑、連線名稱與裝置資訊，分享前請先檢查全文。
