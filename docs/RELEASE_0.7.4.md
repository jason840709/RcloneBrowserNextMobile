# Rclone Browser Next Mobile 0.7.4

- **清理多出的空資料夾**：同步遇到個別檔案寫入失敗時，仍會確認來源並清理目的地多出的空資料夾。來源也有的空資料夾會保留，讀不到來源時不刪除。出錯後不再整個工作重做。
- **記憶卡名稱處理**：寫入 FAT／exFAT 記憶卡或 USB 隨身碟時，結尾是句點或空格的名稱會略過，不會自動改名。完整同步仍會刪除目的地多出的項目，被略過的名稱不會重新補回。
- **詳細頁與報告**：新增「刪除的資料夾」「略過的名稱」，錯誤也會按資料夾統計，方便找出哪些資料夾沒有傳成功。
- **匯出傳輸報告**：在傳輸詳細頁按「匯出報告」，可儲存並分享這次傳輸的設定、結果與錯誤。報告含檔案路徑、連線名稱與裝置資訊，分享前請先檢查全文。
