# Rclone Browser Next Mobile 0.3.0

Android 版 rclone 檔案管理器，內建官方 rclone 1.75.2（Android ARM64）引擎。

支援單頁、分頁與上下雙窗格瀏覽，提供長按多選、複製、移動、背景傳輸與取消，以及兩種可先比對預覽的單向同步模式。沿用桌面版圖示與紫色主題，並支援深色模式。

## 安裝需求

下載 APK 並於 ARM64 裝置安裝（需 Android 8 以上；已於 Android 14 ARM64 模擬器完成驗證）。

## 驗證與限制

目前已通過 48 項引擎測試與 8 項介面流程測試（涵蓋本機與 WebDAV 傳輸、同名略過、空資料夾、背景執行、取消與同步）。

實體 NAS 傳輸速度、SMB／SFTP 實機連線與長時間背景運作仍待更多實測。其他雲端服務需透過匯入設定檔加入；App 被系統終止後不會自動續傳。複製與移動會略過同名檔案，完整同步則會覆蓋不同檔案並刪除多餘項目。
