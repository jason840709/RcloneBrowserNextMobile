# Rclone Browser Next Mobile 0.7.0

## 更新內容

- **傳輸紀錄與詳細頁**：清楚列出每筆工作的模式、來源與目的地；點開可查看新增、更新、略過、刪除與出錯統計，以及逐檔清單。
- **三種同步比對方式**：「讓目的地和來源一模一樣」可選擇「大小與修改時間」、「只比對大小」或「大小與內容」。複製、移動與「只補上缺少的檔案」仍一律略過同名檔案。
- **同時比對檔案數**：可選自動、4、8、16 或 32 個。
- **修改時間未保留提醒**：同步後會抽查檔案時間；若目的地無法保留修改時間導致下次可能重傳，會主動提醒並提供切換比對方式的按鈕。
- **固定同步按鈕列**：捲動同步設定時，「直接開始」與「先比對」按鈕會固定在底部。

## 包含 0.5.0 與 0.6.0 更新

此版本亦包含常用工作、單筆取消、清除紀錄、讀取中提示與無限時同步比對（不再受 90 秒限制，可隨時手動停止）。
