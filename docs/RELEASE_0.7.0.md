# Rclone Browser Next Mobile 0.7.0

## 這次更新

- **傳輸紀錄與詳細頁**：每筆列出操作方式、來源與目的地。點開可查看新增、更新、不用傳、刪除與出錯的數字，以及逐檔清單和傳輸設定。
- **三種同步比對方式**：大小與修改時間、只比對大小、大小與內容，用於「讓目的地和來源一模一樣」。複製、移動和「只補上缺少的檔案」仍然略過同名檔案。
- **同時比對的檔案數**：可選自動、4、8、16 或 32 個檔案。
- **修改時間提醒**：同步後抽查檔案。目的地沒有保留修改時間、下次可能重傳時，會顯示提醒並提供變更比對方式的入口。
- **同步按鈕固定在下方**：捲動畫面時仍能按「直接開始」與「先比對」。

## 從 0.4.0 更新

這一版也包含 0.5.0 與 0.6.0 的功能：常用工作、單獨取消一筆傳輸、清除傳輸紀錄，以及開啟資料夾時顯示「正在讀取」。同步可先比對或直接開始。比對會顯示進度，可以停止，不再因超過 90 秒而被 App 停止。
